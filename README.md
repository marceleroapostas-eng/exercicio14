\# Exercício 14 - Cálculo da Idade



\## Descrição



Este programa solicita o ano de nascimento e o ano atual. Em seguida, calcula a idade da pessoa. Caso o ano de nascimento seja maior ou igual ao ano atual, informa que o ano de nascimento é inválido.



\## Tecnologias utilizadas



\- Java



\- NetBeans



\- Maven



\## Entrada



A entrada contém o ano de nascimento e o ano atual, informados pelo usuário.



\## Saída



O programa informa a idade da pessoa ou informa que o ano de nascimento é inválido.
